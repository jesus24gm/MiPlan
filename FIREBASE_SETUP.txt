===========================================
   CONFIGURACIÓN DE FIREBASE - INSTRUCCIONES
===========================================

Firebase ya está configurado en el código, pero necesitas completar estos pasos:

1. CREAR PROYECTO EN FIREBASE CONSOLE
   =====================================
   - Ve a: https://console.firebase.google.com/
   - Click en "Agregar proyecto"
   - Nombre: MiPlan
   - Habilita Google Analytics (opcional)
   - Click en "Crear proyecto"

2. AGREGAR APP ANDROID
   ====================
   - En el proyecto Firebase, click en el ícono de Android
   - Package name: com.miplan
   - App nickname: MiPlan
   - SHA-1: (opcional, para autenticación)
   - Click en "Registrar app"

3. DESCARGAR google-services.json
   ================================
   - Descarga el archivo google-services.json
   - Colócalo en: app/google-services.json
   - ⚠️ IMPORTANTE: Este archivo NO debe subirse a Git (ya está en .gitignore)

4. HABILITAR CLOUD MESSAGING
   ===========================
   - En Firebase Console, ve a "Cloud Messaging"
   - Habilita la API de Cloud Messaging
   - Copia la "Server Key" (la necesitarás para el backend)

5. CREAR ICONOS DE NOTIFICACIÓN
   ==============================
   Necesitas crear estos iconos en res/drawable/:
   - ic_notification.xml (icono genérico)
   - ic_task.xml (icono de tarea)
   - ic_check.xml (icono de completado)
   - ic_people.xml (icono de colaboradores)
   - ic_comment.xml (icono de comentario)

6. SINCRONIZAR GRADLE
   ===================
   - En Android Studio: File > Sync Project with Gradle Files
   - Espera a que termine la sincronización
   - Compila la app: Build > Make Project

7. BACKEND - CONFIGURAR SERVER KEY
   =================================
   El backend necesita la Server Key de Firebase para enviar notificaciones push.
   
   En el backend, agrega:
   - Variable de entorno: FIREBASE_SERVER_KEY=tu_server_key_aqui
   - O en application.conf:
     firebase {
         serverKey = "tu_server_key_aqui"
     }

8. PROBAR NOTIFICACIONES
   ======================
   - Inicia sesión en la app
   - El token FCM se enviará automáticamente al backend
   - Desde otro dispositivo/usuario, asigna una tarea
   - Deberías recibir una notificación push

===========================================
   SOLUCIÓN DE PROBLEMAS
===========================================

❌ Error: "google-services.json missing"
   → Descarga el archivo de Firebase Console y colócalo en app/

❌ Error: "FirebaseApp is not initialized"
   → Sincroniza Gradle y limpia el proyecto (Build > Clean Project)

❌ No recibo notificaciones push
   → Verifica que el token se esté enviando al backend
   → Revisa los logs: Logcat > Filter: "FCM"
   → Asegúrate de que el backend tiene la Server Key correcta

❌ Error al compilar
   → Asegúrate de tener conexión a internet (Gradle descarga dependencias)
   → Limpia y reconstruye: Build > Clean Project > Rebuild Project
