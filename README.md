# MiPlan - Android App

Aplicación Android para gestión de tareas y tableros Kanban.

## 📚 Documentación

La documentación completa del proyecto se encuentra en:
`C:\Users\Jesus\CascadeProjects\MiPlan\docs\`

## 🚀 Tecnologías

- **Kotlin** - Lenguaje de programación
- **Jetpack Compose** - UI moderna
- **Hilt** - Inyección de dependencias
- **Ktor Client** - Cliente HTTP
- **Coroutines & Flow** - Programación asíncrona

## 🏗️ Arquitectura

- **MVVM** - Model-View-ViewModel
- **Clean Architecture** - Separación de capas
- **Repository Pattern** - Abstracción de datos

## 📱 Características

- ✅ Autenticación de usuarios con JWT
- ✅ Gestión completa de tareas (CRUD)
- ✅ Tableros Kanban con columnas y tarjetas
- ✅ Calendario de tareas
- ✅ Notificaciones push con Firebase
- ✅ Perfil de usuario con avatar
- ✅ Modo offline con Room (sincronización automática)
- ✅ Integración con Cloudinary y Unsplash
- ⏳ Drag & drop (planificado para futuro)
